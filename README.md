# CubaHoy
Aplicación web de noticias CubaHoy lista para subir a GitHub.
Archivos: server.js, index.html, admin.html y package.json.
Para ejecutar: npm install y luego npm start.
App: /  |  Panel: /admin
Demo: usuario `admin`, contraseña `cubahoy-demo`.
Antes de producción cambia ADMIN_USER, ADMIN_PASSWORD y ADMIN_TOKEN.
SQLite es para la primera prueba; producción requiere una base de datos persistente.
